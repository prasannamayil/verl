OVERVIEW
--------
Successfully implemented entropy-based advantage shaping for PPO/GRPO training
in the VERL framework. The method adds an entropy-based term to advantages:

    adv += min(alpha * entropy.detach(), |adv|/kappa)

KEY FEATURES
------------

1. Conditional Execution
   - Only activates when use_entropy_advantage_shaping=True
   - Gracefully degrades to standard behavior when disabled

2. Entropy Computation
   - Reuses existing entropy computation infrastructure
   - Automatically triggers when shaping is enabled
   - No redundant computation if entropy_coeff > 0

3. Advantage Modification
   - Applied after advantage estimation, before policy loss
   - Uses detached entropy (no gradient feedback)
   - Bounded by min() operation to prevent domination

4. Performance
   - Minimal computational overhead (one torch.min per micro-batch)
   - Memory efficient (entropy already computed if regularization enabled)
